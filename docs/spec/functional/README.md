# Fachliche Spezifikation

Einzige Quelle der Wahrheit für das WAS. Sie enthält keine Technologie (weder Plattform noch Sprache noch Werkzeuge noch Namen konkreter Objekte).

- Sprache der Dateien: Deutsch. IDs: `FR-<BEREICH>-<NN>` (funktional), `NF-<BEREICH>-<NN>` (nichtfunktional).
- Status: `beschlossen`, `Vorschlag`, `offen`. Nur `beschlossen` wird auf Tests geprüft.
- Ebenen: `unit`, `integration`, `e2e`. Die Spalte nennt, auf welchen Ebenen die Anforderung getestet sein muss.
- Änderungen nur auf ausdrückliche Anweisung des Nutzers.

Dateien: 01-scope, 02-glossary, 03-requirements, 04-parameters, 05-reference-case, 06-open-points.
